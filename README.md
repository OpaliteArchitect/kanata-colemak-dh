# Colemak-DH .kbd file for Kanata

[Colemak-DH](https://colemakmods.github.io/mod-dh/) ANSI layout with Extend layer .kbd configuration file for [Kanata](https://github.com/jtroo/kanata). Inspired by [DreymaR's EPKL](https://github.com/DreymaR/BigBagKbdTrixPKL). 

This is based directly on [Colemak Mod-DH Kanata template](https://github.com/ColemakMods/mod-dh/blob/master/kanata/colemak-dh-ansi.kbd).

## How to Use

1. Download [Kanata](https://github.com/jtroo/kanata/releases/latest) for your operating system.
2. Get `kanata.kbd` [from this repository](https://github.com/OpaliteArchitect/kanata-colemak-dh/blob/main/kanata.kbd) and place it in the same folder as _Kanata_.
3. Run _Kanata_.

### If you're on Windows and want a ready to run package:

1. Go to [**Releases**](https://github.com/OpaliteArchitect/kanata-colemak-dh/releases) and download `kanata-v1.12.0-windows`.
2. Extract the `.zip` file and run `kanata_windows_gui_winIOv2_x64.exe`.
